What is a continuous system?
• Continuous systems are those types of systems in which input and output
signals are the same at both the ends.
• In this type of system, variable changes with time and any type of variation is not
found in the input and output signal.
• In response to the input signal, a continuous system generates an output signal.
Source: https://www.javatpoint.com/continuous-systems-vs-discrete-systems
Example:
Two variables x and y and both vary with time. Continuous signals are represented within 
parenthesis.

Predator-Prey Models
These models are intended to model two species
whose populations are very closely dependent on
each other, much in a way they are expected to
work in the wild.
=== M3-MAIN - Modeling Continuous Systems.pdf | page 13 ===
The predator-scenario usually produces cycles in the population numbers
of both species:
(1) Prey population increases
(2) Predators feast on plentiful prey
(3) Predator population increases
(4) Copious predators overhunt the prey population
(5) Prey population decreases
(6) Predators starve
(7) Predator population goes down
(8) Prey is less vulnerable to dwindled predator population
(9) Prey species thrives
(Repeat from step 1)
=== M3-MAIN - Modeling Continuous Systems.pdf | page 14 ===
Usually the predator-prey model is specified mathematically by the
following two equations:
referred to as Kolmogorov’s predator-prey model
where x – population of prey & y – population of predator.
Note that in each equation, the change in population is proportional to the
current population, such that f(x, y) and g(x, y) define the fractional, or
per capita, growth rates in the populations ( f is the derivative ln x).
In the model, it is said that as the predator population, y, increases, the
growth rate of the prey population of x, declines. (steps 3-5).
=== M3-MAIN - Modeling Continuous Systems.pdf | page 15 ===
It is further assumed that as the prey population, x, increases, the
predator growth rate increases. (steps 1-3).
Lotka-Volterra Model
f = b – py
g = rx – d
NOTE: The model is designed such that f is linear in y with a negative
slope, and g is linear in x with a positive slope.
=== M3-MAIN - Modeling Continuous Systems.pdf | page 16 ===
After simplifying the equations using formulas by Kolmogorov’s and
Lotka-Volterra models:
C = b ln y – py – x + d ln x
This is a conservation law that holds for all x(t) and y(t).
The particular forms of x(t) and y(t) depend on the choices of b, p, r and
d, and the initial conditions at time zero.

The M Files
MATLAB allows writing two kinds of program files:
•Scripts −script files are program files with .m extension. In these files, you write series of
commands, which you want to execute together. Scripts do not accept inputs and do not return any
outputs. They operate on data in the workspace.
•Functions −functions files are also program files with .m extension. Functions can accept inputs
and return outputs. Internal variables are local to the function.

The Menu Function
• MATLAB has a built-in function called menu that will display a Figure Window with pushbuttons 
for the options.
• The first string passed to the menu function is the heading (an instruction), and the rest are labels 
that appear on the pushbuttons.
•
The function returns the number of the button that is pushed.
Example:
%This is script as the user for a type of pizza
% and prints which type to order using a switch
pick = menu('Pick a Pizza','Cheese','Sausage','Mushroom');
switch pick
case 1
disp('Order a cheese pizza')
case 2
disp('Order a Sausage pizza')
case 3
disp('Order a Mushroom pizza')
otherwise
disp('No pizza for us today')
end
