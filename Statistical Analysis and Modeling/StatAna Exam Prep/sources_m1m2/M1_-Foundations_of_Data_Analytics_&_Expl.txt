Descriptive Measures using Excel
Functions
What is Does
SUM(range)
sumif(ranger, criteria, sum_range)
Adds a range  of cells.
Add cells from sum_range if the condition specified in criteria on range is met.
AVERAGE(range)
AVERAGE(range,criteria,average_range)
Calculates the mean(arithmetic average) of a range of cells.
Calculates the average_range if the condition in criteria on range is met.
MEDIAN(range)
Calculates the median value for a data set; half the values in the dataset are 
greater than the median and half are less than the median.
MAX(range)
Returns the maximum value of a dataset.
MIN(range)
Returns the minimum value of a dataset.
SMALL(range, k)
LARGE(range, k)
Returns the kth smallest or kth largest value in a specified data range.

Statistical Process Control
Descriptive Analytics Use-Cases
• Methodology for monitoring a process to identify special causes of variation
and signing the need for corrective action.
• Reality: Every process varies
• Goal: To reduce variation in products, services, or processes
• Types of variations:
❖Common Cause Variation – These process produce variations which can be
considered natural or common to the process and will nearly always be present.
In the statistical world, these processes are in control.
❖Special Cause Variation – These types of processes display larger amounts of
variations ( not present in common cause variation) and often stem from
external sources and are considered not in control
